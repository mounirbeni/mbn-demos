# CLAUDE.md

Static sales demos of MBN DEV (coffee, barber, beauty, law + secretary desk, rent, ceramics), split out of `mounirbeni/mbndev`. Repo `mounirbeni/mbn-demos` (public) → Vercel project `mbndev-demos` (https://mbndev-demos.vercel.app).

- No build, no backend. Each demo lives in `public/demos/<slug>/` and uses absolute paths `/demos/<slug>/…`; clean URLs `/demo/<slug>[/admin|/secretary]` are rewrites in `vercel.json`. `/` redirects to https://mbndev.ma/portfolio.
- Demo data stays in each visitor's localStorage.
- PIN gate / on-off / expiry are still owned by the platform: `js/gate.js` calls `https://mbndev.ma/api/demos/<slug>/config|unlock` (cross-origin; the platform's CORS allow-list includes this project's domain). Managed from `/dashboard/admin/demos` on the platform (`backend/src/lib/demos.js` → `CATALOG` holds this project's URLs).
- Every public page loads `public/demos/_shared/wa-chat.js` (floating WhatsApp chat).
- Rule kept from the platform: every office-type demo (law, clinic, agency…) ships a secretary desk with its own dashboard, linked via `deskPath` in the platform's `CATALOG`.
- CSP in `vercel.json`: `connect-src` must keep `https://mbndev.ma` for the gate.
- `ceramics` (Atelier Safi, a Safi ceramics artisan): workshops and courses in Morocco and abroad — sessions calendar, booking with deposit and waiting list, "notify me in my city" demand list, host-a-workshop requests, participant space (reference + phone), and an atelier dashboard (sessions/rosters/attendance, bookings, manual bookings, inbox, demand by city, payments, CSV). Content and example prices in `js/config.js`; classic scripts (no modules), data in `js/store.js`. Also: FR/EN/AR (RTL) switch, programme per format and session detail, gift vouchers (buy + redeem at booking), group/company requests, small shop with orders, reviews moderated before publishing, consent checkboxes + legal pages (terms/privacy/legal notice in `config.js`), a log of automatic messages (confirmation, day-before reminder, waiting list, voucher, order) and announcements to a city interest list or session participants. Store key `atelier_safi_v2`.
- Prospect demos (lighter, shared kit `_shared/kit.css` + `_shared/kit.js`, classic scripts, no platform gate — local dashboard PIN shown on screen): `moto` (Tamouda Mobility, scooter/moto rental in Agadir: live availability per unit, degressive prices, hotel delivery zones, booking lookup/cancel; dashboard today/bookings/14-day planning/fleet & prices/revenue/WhatsApp messages, PIN 2026, store `tamouda_moto_v1`), `cuisine` (EPS Design Cuisine, made-to-measure kitchens: gallery, kitchen estimator, free measuring visit booking; dashboard pipeline/agenda/projects/estimator prices/stats, PIN 1985, store `eps_cuisine_v1`), `photo` (Magic Vision Nador, photo & video: portfolio, packs, date availability with 48 h hold, private client gallery with album picks; dashboard bookings/calendar/galleries/revenue, PIN 2611, store `magic_vision_v1`), `export` (Coopérative Avenir d’Exportation de Céramique, B2B export: FR/EN catalogue with refs/MOQ/indicative FOB prices, quote basket + export quote request; dashboard quote requests with per-line pricing, status flow, proforma CSV, catalogue prices/visibility, stats by country, PIN 7205, store `avenir_export_v1`). Photos are Unsplash placeholders; prices are examples.
